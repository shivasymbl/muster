# 1. Public site

Status: Done.

Muster is the overlap grid for a hiring panel. The public site at https://muster.asymbl.app says that in one pass: a recruiter sets the window, sends one link, and the candidate, the hiring manager, and the client each mark the times they can make.

The home page uses the Muster wordmark and the consent mark. The sample week is a recruiting week: recruiter screen, hiring manager interview, client interview, offer call.

`/privacy-policy` and `/terms` are readable without JavaScript, with the same words as the in-app pages. The privacy page names Asymbl Inc and muster@asymbl.com.

Done when a logged-out visitor can read the home page, the privacy page, and the terms page, and the pages say Muster.
