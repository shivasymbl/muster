# 4. A muster is a link

Status: Done.

Anyone with the link can open a muster and answer it. They do not need an account. A candidate can mark times from the link a recruiter sent.

Signing in does not lock the page. The signed-in home list shows musters the person owns, was invited to, or has already answered. It does not list every muster in the database.

A missing muster and a muster the caller cannot see return the same not-found result on the assistant. The website still opens a muster by its link.

Done when a logged-out browser can answer a link, and a signed-in person still cannot use that fact to list other people's musters.
